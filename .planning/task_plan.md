# Task Plan — 复刻哪吒打字「文章打字交互」

## Goal
把 nezhadazi.com「打字练习文章大全」里**文章打字的交互方式**提取出来，做成一个
**独立可运行**的网页 Demo，配一条完整工作链条：

```
主界面（文章列表）
   ├ 选内置文章
   └ 导入自己的文章
        ↓ 点开某篇
   打字交互页  ← 本次要"提取"的核心
        ↓ 打完
   结算页（照搬原站结算模式）
        ↓
   ├ 下一篇
   └ 返回主界面（该篇标记"已完成"，可再次练习）
```

## 用户明确的对齐点（已确认）
1. **拼音只是提示**；判定标准是**必须打出正确的汉字**（用户用自己输入法）。
2. **不要桌宠**。其它界面观感要**还原**。
3. 工作链条如上：网址 → 主界面 → 选/导入文章 → 交互 → 结算 → 下一篇/返回。
4. 已完成的文章显示「已完成」，但**可以再次练习**。
5. 交付形态：可运行的独立网页 Demo。

# 第四轮：逐格对齐 + 万字上限 + 交互组件视觉还原（2026-10-11）

## 需求
用户：「① 打出的每一个汉字和标点符号都应该和练习文案的单体对齐（举例如上「一二三」下「一二三」逐字对齐）；
② 上传文章字数有没有限制，要有的话确保一万字以上；③ 交互界面的视觉效果没达到原网站，线条/宽度/颜色深浅要尽量还原」

## Phases
| # | 阶段 | 状态 |
|---|------|------|
| C1 | 拉原站 `level.css`（53,767B）/ `student.js`（150KB）逐项比对取值 | complete |
| C2 | 定位不对齐根因（双方 padding + 边框偏移 + 宽度漂移累积） | complete |
| C3 | `css/level.css` 按原站取值整篇重写（卡片/下划线/顶栏/面板/深色/底栏） | complete |
| C4 | `js/engine.js` 加 `measureWidths()` / `applyCharWidths()`，把每格宽度钉死 | complete |
| C5 | `js/app.js` 字数上限 50000 / 警告阈值 10000 / 实时字数 | complete |
| C6 | 万字长文渲染提速（拼 HTML 一次性落地）+ 打超续行 + 行首无错音 + resize | complete |
| C7 | 无头回归（对齐 0.00px / 深色 / 背景 / 结算 / 万字 / file://）+ 截图 | complete |
| C8 | 归档（产品底线.md / findings F14 / progress.md / 本表） | complete |

## 结论要点
- 原站**没有**"已打内容镜像层"，对齐是「同字体 + 全局 `padding:0`」的自然结果；
  任何一边加水平 padding 都会破功（本项目踩过，已写成红线）。
- 为防字体回退/全角半角标点/空格导致的宽度漂移沿行累积，本项目额外钉死每格宽度，
  实测偏差 **0.00px**（39 字行含 7 个标点；字号 8 档同样 0.00px）。
- 卡片宽度模型 = `max(900px, 内容宽 + 7px)` 且 `≤1200px`，与上表实测一致。
